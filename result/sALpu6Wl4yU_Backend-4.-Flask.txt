Что такое Flask? Flask — это микрофреймворк для языка Python для создания веб-приложений. Приставочка micro в слове микрофреймворк не означает, что наше приложение будет помещаться в один файл, хотя мы можем так устроить.

И вследствие этого появляется очень много расширений для Flask, которые делают его достаточно гибким и позволяют работать с многими вещами, такие как веб-формы, базы данных и прочие подобные вещи, которые по умолчанию в ядре Flask не поддерживаются, но существует достаточно много расширений, которые позволяют с этими вещами работать.

В этом примере познакомимся с еще двумя данными Flask. Первый называется Flask SQL Alchemy. Это расширение, которое предоставляет оболочку к довольно популярному пакету, который просто называется SQL Alchemy.
Он предоставляет ORM для базы данных. ORM позволяет приложениям управлять базой данных с помощью использования объектов высокого уровня. Например, в данном случае это будут просто классы. И задача ORM сделать общение с базой данных более удобным и перевести операции высокого уровня, такие как вызовы методов и классов, в команды уровня баз данных.
Самое приятное, что есть в пакете SQL Alchemy, это то, что она предоставляет ORM не для одной, а для многих революционных баз данных. Она поддерживает довольно длинный список баз данных, которые включают в себя такие базы, как MySQL, Postgres и SQLite.
Это довольно хорошо, потому что можно не завязываться на каком-то определенном сервере базы данных и в случае чего безболезненно его поменять. Чтобы установить расширение для Flask SQL Alchemy, нужно, опять же, просто выполнить pip install или установить пакеты, которые есть в requirements.txt в репозитории.

Для того, чтобы выполнять эти задачи, нам предоставляется механизм миграции, который создаст отдельный каталог ну или директорию с названием migrations и будет туда класть информацию о всех изменениях, которые мы к базе данных применяли.

После того, как мы создали директорию или репозиторию миграции, мы можем создать первую миграцию баз данных, которая будет включать в себя добавление таблицы users, которая сопоставляется с моделью, которую мы прописали в модуле models.py.
Существует два способа создания миграции. Создание миграции баз данных автоматическое и ручное. Для автоматического создания миграции пакеты сравнивают схему баз данных, определенную моделями баз данных с фактической схемой, которая в базе данных есть.
