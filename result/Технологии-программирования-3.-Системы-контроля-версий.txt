А с другой стороны у вас есть bare репозиторий. Чистый. В котором находится только git репозиторий. Как вы думаете, каким образом хранятся репозитории на git сервере? В каком виде? В классическом или в bare?
В bare виде. То есть как раз, когда мы клонируем какой-то репозиторий. Вы могли обратить внимание на ссылку. Что у вас название репозитория. Это название репозитория .git. Так вот, это просто папка.
В которой как раз хранится bare репозиторий. Название папки .git. Давайте я сейчас как раз попробую инициализировать bare репозиторий. А, я окей. Я на домашнем компьютере. И мы выполняем команду git init . bare.
Вот, у меня тут ошибка, но в целом смотрите. Вот он вывод утилиты 3. То есть у нас сразу появляется содержимое папки .git. То есть у нас есть branches, у нас есть config, description, head и так далее.
Если мы просто создадим с вами папку git init. Так, давайте, mkdir classic repo. Выполняем команду git init. Вот, и у нас получается есть отдельная папка, которая называется .git. Вот, и она ровно такая же.
То есть у нас папка .git хранится в локальной репозитории. Более того, мы можем теперь, смотрите, что сделать. Мы можем сделать следующее. Написать git clone git repo. То есть вам не обязательно подключаться к другому репозиторию.
К внешнему серверу вы можете склонировать репозиторию локально. Вот, то есть вы можете даже на своем сервере это все дело хранить. Все, так. Давайте тогда зафинализируем, что мы сегодня с вами узнали.
