Идея следующая. У меня есть специальный формат файла. Вот resources, папку, в которую кладут ресурсы. Есть разрешение .properties. В нем записываются определенные параметры запуска приложения в формате ключ-значение.
Разделителем может быть либо просто пробел, либо равно, либо двоеточие. Идея вам подсказывает, что, пожалуйста, делайте всегда через равно. Это действительно самый лучший вариант, и плюс-минус стандарт.
Как нам читать такие вот properties? Удобно. Для этого в Java существует специальный класс properties — java.util.properties. Мы создаем java.util.properties.props равняется new properties.
