# Датасет

Таблица лежит в [`data/lectures.csv`](https://github.com/Mihaham/Whisper_FPMI/blob/main/data/lectures.csv). Кодировка UTF-8 с BOM, чтобы Excel открыл русский текст без ручной настройки. `build` пишет рядом `data/lectures.jsonl`: те же поля, по одному JSON на строку. В git публикуется CSV.

Собрать заново:

```powershell
python -m whisper_fpmi build
```

`build` читает `result/` и `download/`, забирает описания с VK и пишет CSV, JSONL, облако, граф, поисковый индекс и `data/metrics.json`.

На момент последней сборки в таблице **2331** лекция. С роликом VK сопоставилось **1252**: у файла есть ссылка в шапке или имя совпало с текущим названием на канале. У **1079** старых файлов имя не совпало с сегодняшним названием ролика, поэтому лектор и главы у них пустые. Это не дыра в парсере таймкодов, а отсутствие описания.

## Колонки

| Колонка | Смысл |
|---------|--------|
| `slug` | Имя файла без `.txt` |
| `video_id` | Идентификатор VK, например `-206078025_456241617` |
| `title` | Номер и тема так, как они показаны в каталоге |
| `header_title` | Название из шапки файла, если шапка есть |
| `course` | Курс, поток и тег |
| `number`, `stream`, `tag` | Куски разбора имени |
| `kind` | `лекция`, `семинар`, `допсем`, `консультация` или `липс` |
| `lecturer` | Лектор, семинарист или преподаватель из описания. Оператор и монтажёр не берутся |
| `event_date` | Дата из строки «Дата …: ДД.ММ.ГГГГ», в виде `ГГГГ-ММ-ДД` |
| `url` | Ссылка на ролик |
| `model`, `language`, `transcribed_at` | Из шапки расшифровки |
| `plain`, `timed` | Пути к сплошному тексту и к интервалам |
| `duration_sec` | Конец последнего интервала Whisper, в секундах |
| `vk_duration_sec` | Длительность в карточке канала |
| `segments` | Число интервалов Whisper |
| `median_segment_sec`, `max_segment_sec` | Типичная и самая длинная реплика. Очень длинный интервал — признак, что Whisper склеил кусок |
| `speech_sec`, `gap_sec` | Сумма длин интервалов и паузы между ними дольше 0,3 с |
| `chars`, `words`, `wpm` | Объём текста и слов в минуту |
| `function_words`, `function_per_1k` | Служебные слова: предлоги, союзы, местоимения |
| `fillers`, `filler_per_1k` | Слова-паразиты: «значит», «давайте», «как бы», «то есть» |
| `filler_counts` | Разбивка паразитов: `значит=12; давайте=4` |
| `lexical_density` | Доля содержательных слов среди всех токенов |
| `unique_lemmas` | Сколько разных содержательных лемм |
| `timecode_count` | Сколько глав разобрано из описания |
| `timecodes_with_hour_field` | Сколько меток записаны как `ЧЧ:ММ:СС`, даже если час равен нулю |
| `timecodes_past_one_hour` | Сколько меток стоят на 1:00:00 и позже |
| `timecodes` | Сами главы: `01:05:30 После часа; 04:54:28 Следующая тема` |
| `description` | Текст описания VK |

Пример из таблицы: консультация по математической статистике длится около пяти часов (`duration_sec` ≈ 18089). В описании 50 глав, 30 из них позже первого часа, последняя — `04:54:28`. Лектор в описании указан отдельной строкой, и он попадает в колонку `lecturer`.

Леммы считает pymorphy3. Если пакета нет, остаётся суффиксный стеммер, и облако с графом нужно пересобрать: хук перед пушем это заметит.
