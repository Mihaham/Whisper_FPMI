# Идея

На канале лектория ФПМИ больше двух тысяч записей: лекции, семинары, допсемы, консультации. Смотреть ролик, чтобы найти одно определение, долго. Текст с привязкой ко времени решает другую задачу: лекцию можно прочитать, найти слово и открыть видео с нужной минуты.

## Что хранится

Репозиторий не зеркало видео. После расшифровки остаются два текста на лекцию.

| Папка | Файл | Зачем |
|-------|------|--------|
| `result/` | `название.txt` | Сплошной текст, его читают и по нему считают слова |
| `download/` | `название.mp4.txt` | Те же слова, нарезанные Whisper на интервалы `[начало --> конец]` |

Имя файла — это название ролика, приведённое к одному виду: курс, номер, тема, иногда поток (`основной`, `продвинутый`) или тег (`[Допсем]`, `[Семинар]`, `[Консультация]`). Разбор имени делает `parse_stem` в `whisper_fpmi/names.py`. Из него же собирается [каталог](https://github.com/Mihaham/Whisper_FPMI/blob/main/CATALOG.md): курс, номер, ссылка на текст и, если есть, на интервалы.

Старые расшифровки сделаны моделью Whisper `medium`. Новые пишутся `large-v3`. В шапке нового файла есть название, ссылка VK, модель, язык и дата. У старых файлов шапки нет: там сразу текст.

## Что добавилось поверх текстов

Когда текстов стало больше двух тысяч, одного каталога мало.

1. **Таблица по видео.** Название, курс, длительность, лектор, число глав в описании, служебные слова, темп речи.
2. **Облако слов** по леммам всего корпуса, чтобы было видно, о чём лекторий говорит чаще всего.
3. **Главы из описания VK**, включая записи длиннее часа. Это ручная разметка: люди уже проставили `01:05:30 — тема`.
4. **Граф терминов курса**: какие слова держатся вместе и в каких лекциях они звучат.
5. **Поиск без нейросети** и **ответ с цитатой** на фрагмент с таймкодом. Качество поиска измеряется теми же главами из описаний.
