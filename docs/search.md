# Поиск и RAG

Поиск не вызывает модель. Текст лекции режется на фрагменты примерно по 140 слов, с перекрытием и без склейки через паузу длиннее 30 секунд. У длинного интервала Whisper время внутри куска оценивается по доле символов, чтобы глава не прилипала к началу шестиминутной реплики.

Фрагменты индексируются BM25 по леммам. Индекс — `data/search.pkl`, около 420 МБ, в git он не входит и собирается командой `build`. На последней сборке в индексе **221027** фрагментов.

```powershell
python -m whisper_fpmi search "жорданова клетка"
python -m whisper_fpmi search "ординалы" --course "Матлог"
python -m whisper_fpmi rag "что такое перечислимое множество"
python -m whisper_fpmi serve
```

`serve` поднимает страницу на `http://127.0.0.1:8765`: строка поиска, ответ с цитатами, облако и граф.

Ссылка на ролик получает параметр времени. Метка на `1:05:30` превращается в `t=1h5m30s`.

Если запрос почти совпадает с названием лекции, фрагменты этой лекции получают заметную прибавку к счёту. Одно случайное общее слово такую прибавку не включает: иначе глава «определение ординалов» уезжала бы на любую лекцию со словом «определение» в заголовке.

## Ответ

RAG по умолчанию **экстрактивный**. Из найденных фрагментов выбираются предложения, в которых есть слова запроса, и к каждому ставится номер цитаты. Рядом — курс, название, таймкод и ссылка.

Если заданы `OPENAI_API_KEY` или `FPMI_LLM_URL` (и при необходимости `FPMI_LLM_KEY`, `FPMI_LLM_MODEL`), команда `rag` просит модель сформулировать ответ по тем же фрагментам. Метрики ниже посчитаны без внешнего API: проверяется, из нужного ли места взята цитата и не появились ли в ответе слова, которых нет в цитатах.
