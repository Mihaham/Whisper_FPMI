# Расшифровка

Актуальный код живёт в пакете `whisper_fpmi`. Скрипты старого пайплайна YouTube + Whisper `medium` лежат в `legacy/` и для новых лекций не используются.

## Круг

`python -m whisper_fpmi run` повторяет один и тот же круг, пока на канале не кончатся ролики без текста.

1. Список видео канала VK (`vkvideo.ru/@lectorium_fpmi`).
2. Пропуск того, что уже есть в `result/` или в `data/processed.json`.
3. Скачивание пачки **в самом низком качестве, но со звуком**, пока пачка не упрётся в **3 ГиБ**.
4. Несколько лекций качаются сразу. У каждого ролика yt-dlp берёт несколько HTTP-потоков на фрагменты HLS.
5. Whisper `large-v3` расшифровывает пачку. Если есть GPU, основная работа на нём; рядом может считать один CPU-процесс, и GPU его не ждёт.
6. Исходник удаляется. На диске остаются два текста.
7. Каталог пересобирается.

В терминале три полоски прогресса: текущее видео у каждого воркера, пачка 3 ГиБ и все оставшиеся лекции.

## Команды

```powershell
python -m pip install -r requirements.txt
# ffmpeg должен быть в PATH

python -m whisper_fpmi catalog
python -m whisper_fpmi list
python -m whisper_fpmi run
python -m whisper_fpmi run --limit 1
python -m whisper_fpmi transcribe .\file.mp4 --title "Название лекции"
```

Полезные флаги `run`:

| Флаг | Смысл |
|------|--------|
| `--max-gb 3` | Сколько гигабайт держать в `videos/` за один круг |
| `--download-workers 4` | Сколько лекций качать одновременно |
| `--fragment-threads 8` | HTTP-соединений на один ролик |
| `--model large-v3` | Модель Whisper, это значение по умолчанию |
| `--device cuda` или `cpu` | Где считать |
| `--cpu-workers 0` | Только GPU |
| `--gpu-workers 0` | Только CPU |
| `--cookies cookies.txt` | Если VK просит логин. Файл в git не попадает |
| `--keep-video` | Не удалять скачанный файл |
| `--no-skip-existing` | Перешифровать даже готовый текст |

Первый запуск скачивает модель `large-v3`, это несколько гигабайт. Уже лежащие в `result/` лекции скрипт пропускает.

## Что пишет Whisper

Шапка нового файла:

```text
# Название: ...
# Источник: https://vk.com/video-206078025_...
# Модель: whisper large-v3
# Язык: ru
# Дата: 2026-09-28T23:55:43Z
```

Интервалы в `download/*.mp4.txt`:

```text
[00:05.810 --> 00:19.810]  текст фрагмента
[01:05:30.000 --> 01:06:10.000]  фрагмент после часа
```

Сплошной текст в `result/` — те же реплики, склеенные в абзацы. Именно он идёт в облако, таблицу и подсчёт слов. Интервалы идут в поиск: у каждого куска есть начало и конец.

Папка `videos/` в git не входит. Туда падают временные ролики и оттуда же они удаляются в конце круга.
