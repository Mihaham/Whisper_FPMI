## Как устроен граф

Вершина — содержательная лемма курса. Размер кружка — сколько раз слово встретилось. Ребро — слова, которые ходят по одним и тем же лекциям. Вес ребра — индекс Жаккара: число общих лекций делить на число лекций, где есть хотя бы одно из двух слов. Слабые пары отбрасываются, у каждой вершины остаётся не больше четырёх самых тесных связей, иначе картинка становится клубком.

Слово, которое есть почти в половине всего корпуса, в граф курса не берётся: оно не отличает темы. Внутри курса остаются слова с достаточной частотой. На курс берётся до 40 таких слов.

На последней сборке: **187** курсов, **7431** термин, **14445** рёбер, средний Жаккар оставленных рёбер **0,84**.

На странице можно сменить курс, оставить на рисунке только слова по фильтру, перетащить вершину и увидеть список лекций, где термин есть. Если у лекции есть ссылка VK, она открывается из списка.
